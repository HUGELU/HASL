VOLUNTEER COMPUTE

More PCs.
More images in parallel.

Each joined PC runs complete image jobs. A group coordinator keeps the queue;
workers supply their own models, compute and electricity.

Host a worker group

Create an invitation for each person or PC you want to join. Keep invitations private.

TLS encrypts jobs. The invitation pins the group certificate. Stopping the group revokes its invitations and cancels shared jobs.

Contribute this PC

Set up the image engine first. Then paste an invitation from a group you want to help.

Only image-generation parameters are accepted. Your local thread and time limits apply. Leaving stops the current donated task. This PC sees and locally stores the received task and output.

PCs need a reachable LAN or private-network address. Internet routing, NAT traversal, public peer discovery and torrent-style model sharing are not included in this release. This shares independent jobs; it does not pool VRAM across the internet.

06 / LEARNING & UPGRADES

Improve from evidence.

Teach a distinction. Compare alternatives. Keep a better result. Each experiment records its inputs, measurements and outcome.

1. Teach recognition

Leave blank for an independent example. Use one group for similar shots of the same subject, so they stay in the same split.

2. Compare recognition methods

Six centroid and nearest-neighbour candidates learn from training examples. Separate validation examples select the winner. Audit examples report an estimate afterward.

The built-in recognizer learns small image and byte features. It needs your examples; its predictions are not general visual understanding.

3. Connect local models and a compiler

This optional SDXL training and video worker uses a separate configured model environment. The main Image studio has its own automatic native setup and needs no Python.

SDXL inference can run on CPU or CUDA. This worker's LoRA training and CogVideoX video path require CUDA. Use Diagnostics to test the actual device. Open the local-model setup guide.

Automatic source evolution currently changes the validated numeric recognition kernel. It tests the host and archives a new executable. Model-written source reviews remain proposals.

4. Generate and improve media locally

Training uses up to 64 captioned training images and 16 separate validation images. Loss measures denoising error. Review the paired images before using an adapter.
