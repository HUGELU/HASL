ORIGIN-0 v1.6 adds Concept Studio, an encrypted internet relay and practical generation controls while retaining the native image generator and previous research workspace.

**Extract `ORIGIN0_WINDOWS_v1.6.zip` and double-click `ORIGIN0.exe`.** In Image studio, choose Set up image engine. The executable includes the CPU runtime; first setup downloads a verified 6.52 GB Z-Image-Turbo model pack. No Python, API key or service subscription is required for native image generation.

New in this release:

- Concept projects, prompt attributes, bounded Openverse/SearXNG image collection, reviewed captions/categories and duplicate grouping.
- Separate training/validation/audit data, six small classifier candidates, exact logical exercises, rollback, dataset export and project-specific optional LoRA inputs.
- Previewed recipe contributions through draft GitHub pull requests.
- Outbound HTTPS worker connections through an operator-deployed relay; job envelopes are end-to-end encrypted.
- Hardware inventory and resource-aware starting settings, photographic prompt helpers, batches, random seeds, queue history and four-part feedback.
- One-image revision with adjustable strength, rough sampling previews and reusable generation metadata.
- Preference learning from at least three rated results for the same prompt/reference. This changes selected settings, not native model weights.
- Voice-to-prompt with a configured transcription provider.
- A server-enforced PIN screen, private recovery code and restart/inactivity locking.

The release pipeline requires source/race checks, browser exercises, Windows native execution and actual text-to-image **and image-to-image** PNG generation before publication. The included report records the actual run. Small CPU acceptance images verify execution, not photorealism or comparative model quality. The optional GPU drivers, SDXL training and CogVideoX video path have separate requirements and are not covered by this native CPU result.

Windows x64 with AVX2 is the packaged target. Keep at least 10 GB free for setup; 32 GB RAM is a useful laptop configuration. CPU generation can take minutes. A detected GPU is not proof that it supports every model. Android, iOS, universal NPU execution, multi-reference identity locking, neural 4K/8K upscaling and autonomous film production are not included in this release.

Worker PCs execute whole image jobs. A reachable relay server is needed for the new outbound internet route; no public relay is provided. The PIN protects the local interface and APIs, not unencrypted files or the operating-system process.
